# Relationship Manager PWA

A modern, installable **Relationship Manager Progressive Web Application** built with React, Vite, TypeScript, Tailwind CSS, Lucide icons, and Supabase. 

The application helps you manage personal and professional connections, track important life events (birthdays, anniversaries, milestones), and review and dispatch personalized wishes generated by an n8n workflow across WhatsApp, SMS, and Email.

---

## 🌟 Key Features

- **📊 Comprehensive Dashboard:** Real-time metrics computed directly from Supabase, including total connections, events this month, new wishes awaiting action, and sent wishes, plus an upcoming event calendar grouped by date.
- **👥 Connections Directory:** Full CRUD management for relationships with rich attributes (nicknames, communication styles, hobbies, likes/dislikes, structured memories, notes, and contact details).
- **💌 Wishes Hub:** Distinct tabs for **New Wishes** (un-sent) and **Sent Wishes** (history).
- **🚀 One-Tap Wish Launchers:**
  - **WhatsApp:** Direct `https://wa.me/` link with encoded long-form messages.
  - **SMS:** `sms:` protocol link with prefilled short message and phone number.
  - **Email:** `mailto:` link with prefilled subject, body, and recipient address.
  - Quick clipboard copy controls for all formats.
- **🛡️ Sending State Verification:** Opening an external communication app does not assume delivery; users confirm explicitly via "Mark as Sent" to update Supabase records safely.
- **📱 PWA & Offline Support:** Installable on iOS, Android, macOS, and Windows via Service Worker precaching with custom responsive dark UI.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler & Tooling:** Vite 8
- **Styling:** Tailwind CSS v4 (with dark mode theme)
- **Icons:** Lucide React
- **Routing:** React Router v7
- **Database:** Supabase PostgreSQL with `@supabase/supabase-js`
- **PWA Integration:** `vite-plugin-pwa` with custom web manifest and service worker cache
- **Image Processing:** `sharp` for pixel-perfect PWA icon generation

## 🚀 Quick Start Guide

### 1. Prerequisites

- **Node.js:** v18.0.0 or higher (v20+ recommended)
- **npm:** v9.0.0 or higher
- A **Supabase** account and project (or existing database instance)

---

### 2. Installing Dependencies

Clone or open the repository directory in your terminal and run:

```bash
npm install
```

---

### 3. Database Schema & Setup

The database schema matches the specification in `supabase/schema.sql`.

If you are setting up a new Supabase project or verifying existing tables:

1. Open your **Supabase Dashboard** -> **SQL Editor**.
2. Copy and execute the contents of [`supabase/schema.sql`](supabase/schema.sql).
3. The script creates the three core tables:
   - `persons` (uuid `person_id`, contact details, communication styles, structured memories)
   - `events` (uuid `event_id`, `event_date`, `isRecurring`, FK to `person_id`)
   - `wishes` (uuid `wish_id`, `mail_wish` JSONB, `short_wish`, `long_wish`, `"isSent"` boolean, FKs to `person_id` and `event_id`)
4. It also enables Row Level Security (RLS) policies and performance indexes on search and foreign key columns.

*(Optional)* If you need to seed sample test data into an empty database, configure your `.env` and run:
```bash
npx tsx scripts/seed.ts
```

---

### 4. Configuring Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Edit `.env` and fill in your Supabase project credentials (found under **Project Settings -> API** in the Supabase Dashboard):

```env
# Supabase Configuration
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-actual-anon-public-key
```

> **Security Note:** Never put the Supabase `service_role` secret key into client-side `.env` files. The app only requires the public `anon` key.

---

### 5. Running the Development Server

Start Vite in development mode:

```bash
npm run dev
```

Open your browser at `http://localhost:5173`. The application features Instant Hot Module Replacement (HMR).

---

### 6. Building and Previewing for Production

To test the optimized production build and verify service worker generation:

```bash
# Type-check and compile bundle
npm run build

# Preview production build locally
npm run preview
```

---

### 7. Generating PWA Icons

The application includes high-resolution SVG and PNG icons located in `public/icons/`. If you wish to re-generate the icons from source:

```bash
node scripts/generate-icons.js
```

This creates:
- `public/icons/icon-192.png` (Standard PWA launcher)
- `public/icons/icon-512.png` (High-DPI launcher / splash)
- `public/icons/apple-touch-icon.png` (iOS Safari Home Screen)
- `public/icons/maskable-icon-512.png` (Android Adaptive Maskable icon)
- `public/favicon.svg`

---

### 8. Installing the PWA

- **Chrome / Edge (Desktop):** Click the install icon in the address bar or click the in-app **"Install App"** banner.
- **Android (Chrome):** Tap the in-app **"Install App"** button or select *Add to Home screen* from the browser menu.
- **iOS (Safari):** Tap the Share button at the bottom of Safari, then choose **"Add to Home Screen"**.

## 🔧 Troubleshooting Common Issues

### 1. `Supabase environment variables are missing` warning
If you see the amber banner at the top of the app, check that your `.env` file exists in the project root and that `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are populated with your project values (not placeholder strings). Remember to restart `npm run dev` after changing `.env`.

### 2. WhatsApp or SMS buttons are disabled
The buttons are disabled with informative tooltips when the selected connection does not have a phone or WhatsApp number recorded in their profile. Edit the connection to add their contact number.

### 3. PWA install prompt not showing on desktop
Browsers only fire the `beforeinstallprompt` event when the app is served over HTTPS (or `localhost`) and passes manifest validation. If you have previously dismissed the banner, you can clear `rm_pwa_banner_dismissed` in your browser's Local Storage to see it again.

### 4. Supabase Row Level Security (RLS) Errors
If queries return empty lists or permission denied errors, ensure that the RLS policies in `supabase/schema.sql` are applied to allow the anon client key to read and update records.
